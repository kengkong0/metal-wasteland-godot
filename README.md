# 《重装废土：赏金狂飙》(Metal Wasteland: Bounty Overdrive) — Godot 4.x 完整工程

本工程是基于 **Godot 4.x (GDScript)** 开发的 2D 俯视角末世废土战车动作肉鸽游戏，深度融合了：
- **《重装机兵 (Metal Max)》**：`剩余引擎载重 = 战车装甲片 (SP)` 核心公式、主炮/副炮/S-E 三层火力、C 装置全弹发射、战车大破跳车肉搏与战地抢修、10 大赏金首 (WANTED) 悬赏狩猎、明奇博士电击复活、红狼乱入救援。
- **《吸血鬼幸存者 (Vampire Survivors)》**：战场拾取废铁经验即时触发三选一升级（含战场空投武器）、集齐特定武器组合并升至 `★2`（或开启埋藏宝箱）自动融合成 **6 大 `★6` 神话超武**。
- **《土豆兄弟 (Brotato)》**：波次结束返回多拉姆车库刷军火商店、同名同星武器二合一升星、底盘改孔、6 大流派羁绊，以及使用永久货币 **【💎 诺亚晶片】** 的局外轮回养成体系。

---

## 🚀 如何打开与运行

1. 打开 **Godot Engine 4.x**（兼容 Godot 4.0 ~ 4.4+ 标准版）。
2. 在项目管理器中点击 **「导入 (Import)」**，选择本目录下的 [`project.godot`](./project.godot) 文件。
3. 打开工程后直接按 **`F5`**（或点击右上角运行按钮）即可立即开始游玩！
   - 工程内已包含 **49 张高精度 2D 废土机甲/猎人/赏金首/机械兽/地形贴图**（`res://assets/sprites/`）与 **4 首多轨循环 BGM + 14 种实时合成音效**（`res://assets/audio/`），并支持免预导入直读，首次打开即可直接运行。

## 🎮 键鼠与手柄双模式操作指南（即插即用 + 双马达震动反馈）

| 功能动作 | 键盘 + 鼠标操作 | 手柄操作 (Xbox / PS / Switch Pro) |
| :--- | :--- | :--- |
| **驾驶战车冲撞 / 步兵移动** | `W / A / S / D` 或 方向键 | **左摇杆 (`L-Stick`)** 或 **十字键 (`D-Pad`)** |
| **主炮 360° 独立瞄准与射击** | 鼠标移动瞄准 + **鼠标左键/右键**开火 | **右摇杆 (`R-Stick`)** 360° 瞄准 + **`RT / RB`** 开火 |
| **★ C装置：全弹发射** | **`Q` 键** | **左扳机 (`LT / L2`)** 或 **左肩键 (`LB / L1`)** |
| **主动下车 / 登车 / 武道家核爆** | **`E` 键** | **西键 (`X / □`)** |
| **步兵战术无敌翻滚** | **`Space` 空格键** | **南键 (`A / ✕`)** 或 **东键 (`B / 〇`)** |
| **切换主炮自动/手动索敌** | **`R` 键** | **北键 (`Y / △`)** *(在车库内按 `Y` 键可快捷刷新商店)* |
| **战术时停暂停菜单** | **`ESC` 键** 或 **`P` 键** | **`Start / Menu` 键** *(在大本营/车库按 `Start` 直接出击)* |
| **一键静音 / 恢复音频** | **`M` 键** | 暂停菜单内一键切换 |
| **切换大本营页签 / 超武配方** | 鼠标点击顶部按钮 | **`Back / Select` 键** |

    │   ├── DropItem.gd            # 掉落物磁吸拾取与埋藏宝箱超武进化结算
    │   └── FloatingText.gd        # 暴击跳字、激光束、迫击炮预警圈、爆炸冲击波与毒池/水泥潭绘制
    └── ui/
        ├── Main.gd                # 大本营（选人/选车/选图/3档难度/科技树）与明奇博士轮回结算界面
        └── GarageUI.gd            # 多拉姆军火商店、同名升星、底盘改孔、撕取赏金首通缉令与奇遇设施
